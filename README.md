# Poker Arena

A local poker practice arena and bot-training project.

Play against configurable opponent styles, review your decisions, and eventually train and evaluate your own agents.

**Status:** Documentation bootstrap only. The game engine, UI, opponents, and trained models are not implemented yet.

## First milestone

Implement P0: a reproducible heads-up no-limit Hold'em core, filtered observations, legal actions, targeted correctness tests, and a CLI demo.

Setup, test, and demo commands will be added once they have actually run. This project currently makes no claims about playing strength or profitability.
